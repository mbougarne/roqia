# RQ-016 — Acquire and prove the Warsh source format

Status: **planned** · Milestone: **M0**

## Scope

Identify the exact Al Mushaf Al Mohammadi offline artifact, font/pages, version, riwaya/tariq and numbering scheme. Produce a capability report and deterministic sample import/render proof.

Likely implementation touchpoints: maintainer content tooling (future); content provenance records. These paths are targets, not changes already made.

## Acceptance criteria

- [ ] Actual source artifact and provenance exist.
- [ ] Reflow/verse search/Western badges are proved or explicitly unavailable.
- [ ] No OCR, generated text or Hafs-to-Warsh substitution.

## Validation

Compare canonical sample bytes and rendered known-difference passages with qualified review; record unresolved format limitations.

## Handoff and completion
