## Scope

Audit additional states listed in EXISTING-FEATURES.md. Replace false-ready/blank/silent-error states with localized explanation and a concrete recovery action.

Likely implementation touchpoints: all feature controllers and shared state components. These paths are targets, not changes already made.

## Acceptance criteria

- [ ] Every unavailable capability has an honest state.
- [ ] Existing offline content remains usable.
- [ ] Actions do not loop or discard user progress on failure.

## Validation

Cross-feature fault injection and scenario checklist, including no sensor, no pack, low disk and denied permissions.

## Handoff and completion

Record the implementation commit/build, changed paths, actual checks, device/OS where applicable and unresolved limitations. Link related screen captures and source-pack versions. Update this file and backlog.json together. Do not mark done from a mockup or a dependency README alone.
