# RQ-029 — Add edition-aware bookmarks and resume

Status: **planned** · Milestone: **M4**

Dependencies to start: [RQ-011](RQ-011.md), [RQ-024](RQ-024.md), [RQ-025](RQ-025.md).

Screens: 31.

## Scope

Store verse/page locators per edition and current pack version, restore reading position, filter types and handle deleted packs. Do not transplant ordinal positions between editions.

Likely implementation touchpoints: src/repositories/bookmarks/; Quran reader/library. These paths are targets, not changes already made.

## Acceptance criteria

- [ ] Changing edition keeps independent positions.
- [ ] Deleting content preserves bookmarks with re-download action.
- [ ] Version mapping failures are visible and recoverable.

## Validation

Save/kill/reopen, two editions, pack deletion/update and invalid locator fixtures.
