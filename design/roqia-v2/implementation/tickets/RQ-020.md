# RQ-020 — Prove native downloads and file operations

Status: **planned** · Milestone: **M0**

Dependencies to start: [RQ-001](RQ-001.md).

Screens: 35, 48.

## Scope

Evaluate/pin the documented downloader and file/hash adapter on current RN. Prove pause/resume, native reattachment, Wi-Fi restriction, Range/entity validation, durable app-private writes and atomic rename.

Likely implementation touchpoints: src/platform/downloads/ (future); Android compatibility report. These paths are targets, not changes already made.

## Acceptance criteria

- [ ] Target runtime builds and downloads to private storage.
- [ ] Process death/reopen recovers jobs.
- [ ] Range 200/206/416 and entity changes cannot corrupt appended files.

## Validation
