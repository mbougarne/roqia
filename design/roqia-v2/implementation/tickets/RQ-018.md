# RQ-018 — Build content validation and editorial records

Status: **planned** · Milestone: **M3**

Dependencies to start: [RQ-016](RQ-016.md), [RQ-017](RQ-017.md).

## Scope

Validate canonical content, IDs, counts, basmala, fonts and asset hashes. Inventory existing devotional provenance and remove unverified additions. Define correction/version process and reviewer evidence.

Likely implementation touchpoints: maintainer content validation tooling; reviewed devotional source metadata. These paths are targets, not changes already made.

## Acceptance criteria

- [ ] No missing/duplicate source records.
- [ ] Hash and structural failures block publication.
- [ ] Religious rendering/source review is recorded separately from mechanical checks.

## Validation
