# RQ-021 — Implement durable download/install coordinator

Status: **planned** · Milestone: **M3**

Dependencies to start: [RQ-004](RQ-004.md), [RQ-019](RQ-019.md), [RQ-020](RQ-020.md).

Screens: 24, 28, 35, 48.

## Scope

Implement deduplicated jobs, bounded concurrency/retries, transport reattachment, integrity checks, staging/journal/activation and generation-safe events. Completed unrelated files remain usable.

Likely implementation touchpoints: src/features/downloads/; src/repositories/downloads/; src/platform/downloads/. These paths are targets, not changes already made.

## Acceptance criteria

- [ ] Only validated installed bytes become ready.
- [ ] User pause differs from network wait.
- [ ] Crash during file rename/DB commit recovers idempotently.

## Validation

State/HTTP fixtures, disk-full/corrupt files, cancel race and process-death real-device journeys.

## Handoff and completion

Record the implementation commit/build, changed paths, actual checks, device/OS where applicable and unresolved limitations. Link related screen captures and source-pack versions. Update this file and backlog.json together. Do not mark done from a mockup or a dependency README alone.
