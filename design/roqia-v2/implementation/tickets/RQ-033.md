# RQ-033 — Unify devotional and Quran playback

Status: **planned** · Milestone: **M5**

Dependencies to start: [RQ-004](RQ-004.md), [RQ-032](RQ-032.md).

Screens: 08, 10, 11, 12, 13, 14, 38.

## Scope

Define the controller interface independently of redesigned screen completion. Adapt the existing devotional screens first, then let RQ-007–RQ-010 compose that controller. Their final acceptance depends on this integration; this ticket does not depend on those UI tickets being done.

Replace per-screen Video playback with the shared controller after parity. Preserve audio arrays/repeats, expose failures, keep paused mini player and stop on explicit action rather than screen blur.

Likely implementation touchpoints: src/features/audio/; current audio hooks; AdkarScreen; DevotionalListScreen. These paths are targets, not changes already made.

## Acceptance criteria

- [ ] No simultaneous players.
- [ ] All original devotional audio remains mapped.
- [ ] Counters remain independent and paused playback remains controllable.

## Validation

Parity playlist fixtures and navigation/background/focus journeys; remove duplicate player only after proof.
