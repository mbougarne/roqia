# Phase 4 — individual Android captures

56 individual screenshots from the actual Android app. Each screen remains in its own PNG file. Private fixture captures are technical evidence, not approved Quran publication; normal-catalog screenshots are named `empty-*`, `unavailable-*` and `missing-pack-*`.

Western digits are used for UI numbers. Original source ornaments are preserved. Translation and source captures were refreshed after the final layout changes.
