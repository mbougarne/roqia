# iOS app icon

The AppIcon asset uses `ios/app/Images.xcassets/AppIcon.appiconset/icon-opaque-1024.png`, a 1024 × 1024 RGB PNG with no alpha channel. Xcode generates the required sizes from this single image. The original artwork files remain in the repository.

The built-in image generation tool created this opaque variant with the user's authorization on 2026-10-20. The generated square was resized to 1024 × 1024 for the asset catalog.

## Generation prompt

Use case: precise-object-edit. Asset type: 1024 by 1024 pixel iOS App Store app icon for Roqia. Input image: edit target, the existing Quran book icon. Change only the transparent background to a solid warm ivory cream (#F7F5EE), fully opaque all the way to all four square corners. Preserve the entire existing navy blue and gold Quran book illustration, its calligraphy, ornament, angle, pages, ribbon, edges, placement and proportions as faithfully as possible. Keep all artwork inside the square. No extra text, no rounded-corner mask, no external border, no new symbols, no transparency. The book artwork should remain crisp and recognizable at small app icon sizes.
